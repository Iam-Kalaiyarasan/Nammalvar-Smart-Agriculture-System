# 🌾 Nammalvar – Smart Agriculture System

An AI-powered Smart Agriculture Platform developed using **React**, **Django REST Framework**, and **PostgreSQL**. The system helps farmers manage crops, detect diseases, predict suitable crops, sell products directly to customers, and manage orders through an integrated marketplace.

## 🚀 Features

### 👨‍🌾 Farmer
- Farmer Registration & Login
- Farmer Dashboard
- Add, Edit and Delete Products
- Upload Product Images
- View Orders
- Analytics Dashboard

### 🛒 Customer
- Customer Registration & Login
- Browse Marketplace
- Add Products to Cart
- Secure Checkout
- Payment Module
- Order Tracking

### 🤖 AI Features
- Crop Prediction
- Crop Disease Detection
- AI Chatbot for Farming Assistance

## 🛠 Tech Stack

### Frontend
- React.js
- Axios
- React Router
- CSS

### Backend
- Django
- Django REST Framework

### Database
- PostgreSQL

### AI & ML
- TensorFlow Lite
- Google Gemini API

## ⚙ Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
